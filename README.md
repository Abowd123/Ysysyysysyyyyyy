# ColorLand – عالم الألوان 🎨  v1.0.0 (المرحلة 7: نسخة الإطلاق)

> **المرحلة 7 أضافت:** تحميل الرسومات أسرع (الأشكال محسوبة مسبقًا، بدون عمليات هندسية عند الفتح)، موجة التعبئة والعصا أخف بكثير، حماية من الانهيار مع سجل أخطاء محلي يراه الوالدان، شاشة إقلاع برتقالية بلا وميض أبيض، توقيع إطلاق تلقائي من GitHub Secrets، تصغير وتشويش الكود، ملف AAB لـ Google Play، وملفات `docs/`: سياسة الخصوصية، صفحة المتجر، خطة الاختبار مع الأطفال، قائمة الإطلاق.

## ⬇️ تحميل التطبيق
**[حمّل ColorLand.apk (آخر نسخة)](../../releases/latest/download/ColorLand.apk)** · [كل النسخ](../../releases)

كل رفع إلى `main` يبني التطبيق وينشره تلقائيًا في صفحة Releases.

تطبيق تلوين للأطفال (3–10 سنوات) يعمل كاملًا بدون إنترنت، بدون إعلانات، بدون حسابات.

## ما بداخل النسخة 1.0
| الجزء | المحتوى |
|---|---|

| أنماط التلوين | عادي، سحري (المسح يكشف الألوان الحقيقية)، بالأرقام |
| الأدوات | تعبئة باللمس، فرشاة بـ4 أحجام، عصا سحرية، ممحاة، تراجع/إعادة، تكبير بإصبعين |

| مزج الألوان | وعاء مزج بمنطق الصبغات (أصفر+أزرق=أخضر)، الألوان المكتشفة تُضاف للوحة |
| إحياء الرسمة | الرسمة تقفز وتتحرك جزءًا جزءًا بألوان الطفل نفسها + صوت الشخصية + نجوم |

| المعرض والحديقة | كل الرسومات محفوظة وتُستكمل، والرسومات الحية تعيش في الحديقة |
| الوالدين | بوابة (رقم مكتوب بالكلمات)، صوت/موسيقى/اهتزاز، لغة عربي/إنجليزي، وضع عمر صغير/كبير، حد زمني يومي، فتح الكل، مسح التقدم |

## البنية
```
lib/core/      catalog (العوالم والرسومات) · settings · progress (نجوم/شارات) · l10n
lib/engine/    svg_drawing · coloring_document · coloring_controller · brushes · painters
               coloring_canvas · living (إحياء الرسمة) · artwork_storage
lib/effects/   particles · particle_layer · sfx (أصوات + موسيقى)
lib/ui/        screens/ (home, worlds, drawings, coloring, living, gallery, garden,
               achievements, settings, gift, rest) · widgets/ (lolo, bouncy, backdrop, ...)
assets/        catalog.json · drawings/*.svg · audio/sfx · audio/music · fonts
tools/art/     مولّد الرسومات (kit.py + pages_*.py + build_all.py)
tools/gen_sfx.py  مولّد كل الأصوات والموسيقى (أصلية، بلا حقوق)
tools/icon/    أيقونة التطبيق
```

## معاينة الحركة بدون بناء التطبيق
`python3 tools/preview/living_preview.py lion_01 lion.mp4 --seconds 4 --shade`
يرسم «إحياء الرسمة» بنفس منطق `lib/engine/living.dart` إطارًا إطارًا، لمراجعة جودة الحركة فورًا.

## إضافة رسمة جديدة
1. أضف دالة في `tools/art/pages_*.py` (أشكال + `part` للحركة + `animate`).
2. `python3 tools/art/build_all.py --preview` يولّد SVG و catalog.json ويرفض أي منطقة أصغر من المسموح للأطفال.

## البناء
- **GitHub Actions**: كل رفع إلى `main` يبني APK (Actions ← Build ColorLand APK ← Artifacts).
- **محليًا**:
  ```
  flutter create . --platforms=android --org com.colorland --project-name colorland
  python3 tools/release/prepare_android.py   # مهم: بدونه تنهار نسخة release
  flutter pub get && flutter test && flutter build apk --release
  ```

## Google Play لاحقًا
معرّف ثابت، بدون صلاحية إنترنت، بدون SDK تتبع/إعلانات، بوابة والدين. عند النشر: مفتاح توقيع + `flutter build appbundle`.

## قائمة الاختبار على الجهاز
- [ ] التعبئة لا تتسرب في أي رسمة (الأذن الداخلية، العيون، الخدود).
- [ ] الفرشاة لا تخرج من المنطقة، والفرش الخمس تظهر بشكل صحيح.
- [ ] التكبير بإصبعين أثناء الرسم لا يترك خطًا.
- [ ] التلوين السحري يكتمل تلقائيًا بعد المسح، والأرقام ترفض اللون الخطأ.
- [ ] العصا السحرية تكمل الرسمة بموجة.
- [ ] الاحتفال مرة واحدة، و«أحيِها» تحرك الأجزاء بدون ثقوب.
- [ ] إغلاق التطبيق وفتحه: الرسمة والنجوم محفوظة.
- [ ] الموسيقى تتوقف عند الخروج للخلفية.
- [ ] الحد الزمني يظهر شاشة الراحة.
